# The Phuket Edit

An independent, unofficial, mobile-first planning guide for a generic five-night early-December stay at The Pavilions Phuket.

Static HTML, CSS and JavaScript. No backend, analytics, trackers or credentials. Prices are indicative planning estimates, never confirmed bookings. Original CSS/SVG scenery; official hotel photographs are not republished.

Deployment target: GitHub Pages from `main` / root. No build step required.
